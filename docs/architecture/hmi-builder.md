# HMI 빌더 개발 진행 내역

> 최종 갱신: 2026-10-15
> 편집기 2단계까지 커밋 완료(`c838540`).

HMI 빌더는 장비 값을 그래픽 화면으로 보여주고 조작하는 페이지(`#hmi`)다. 사용자가 직접 위젯을 배치하고 속성을 편집해 화면을 만들고, 실행 모드에서 실제 값으로 동작시키는 것이 최종 목표다.

---

## 1. 구성

| 파일 | 역할 |
|---|---|
| `pages/hmi.html`, `js/hmi.js` | 페이지 틀. 실행 모드/디자인 모드 전환, 전체 화면, 권한(Manager 이상)에 따라 [디자인] 버튼 표시 |

| `js/whmi-widgets.js` | 위젯 12종(label, rect, numeric, input, lamp, bar, gauge, tank, button, switch, selector, screenlink) |
| `js/whmi-editor.js` | 편집기(디자인 모드). [디자인]을 누를 때만 지연 로드 |

| `docs/reference/hmi-widgets.md` | 위젯별 props 정의 |

### 데이터 저장 (백엔드 API, `referencs/api-spec.md` §14)

- **HMI 태그**: 레지스터 tagName과 별개의 네임스페이스. `/api/hmi/tags`, `/api/hmi/values`, `/api/hmi/write`.
- **화면**: 장비 DB에 **화면 단위**로 저장.
  - `GET/PUT /api/hmi/project` — 이름, 시작 화면, 화면 순서 (프로젝트 revision)
  - `GET/POST/PUT/DELETE /api/hmi/screens/{id}` — 화면 내용 `content`(`format: "whmi.screen"`), 화면별 revision
  - 낙관적 잠금: 저장 시 revision이 다르면 409(저장한 사람·시각 포함)
  - 제한: id `^[A-Za-z0-9_-]{1,64}$`, 제목 64자, content 256KB, 화면 최대 50개
- **백업/복원**: 백업 ZIP의 `hmi.json`에 프로젝트·화면·태그 포함. 태그는 `unifiedAddress`로 레지스터를 다시 찾아 연결. 복원 화면(설정 → 시스템 유지보수)에 "HMI 화면·태그" 항목이 있음(기본 체크, 레지스터 미복원 시 경고).
- **공장 초기화**: HMI 프로젝트·화면·태그 모두 삭제.

### 사용자 결정 사항

- 화면 저장 단위는 **화면별**.
- 그리는 순서는 자유 — 위젯을 패널(rect) 뒤로 보내는 것도 막지 않음.
- 화면 크기는 장비 해상도가 아니라 **디자인 기준 좌표계**. 실행 시 비율 유지로 확대·축소(여백 가능). 크기를 바꿔도 **위젯 좌표는 유지**(비율 조정 기능 없음).
- 격자 보기와 격자 맞춤은 별도 옵션.
- 위젯 제작은 현재 12종에서 중단(팬 등 추가 위젯은 보류).
- 개발 단계에서는 장비 데이터가 테스트로 바뀌어도 됨 — 무엇이 바뀌었는지만 보고.

## 3. 남은 다듬기 후보

- **장비 비활성 표시 (완료, 2026-10-16)**: `/api/hmi/values`의 `q: "disabled"`(`v: null`)는 런타임에서 통신 불량(`bad`)과 똑같이 그리고(흐리게 + `----`) 쓰기를 막는다. 별도 회색 표시는 두지 않기로 함(단순화).

- 도구줄 버튼이 많아 1600px 폭에서도 거의 꽉 참(메시지 공간 부족), 작은 패널에서는 두 줄로 내려감.
- 작성 중인 JSON을 적용하지 않고 다른 위젯을 선택하면 내용이 사라짐(3단계 속성 편집기에서 해소 예정).
- 화면 삭제 시 다른 화면의 screenlink가 그 화면을 가리키는지 확인하지 않음(실행 시 "화면을 불러올 수 없습니다"로 처리됨).
- 화면 전환 실패 시 상태줄 오류 문구가 다음 폴링의 "갱신 …"에 바로 덮임.
- ⛶ 기호가 글꼴이 없는 브라우저에서 □로 보일 수 있음 → 필요하면 SVG 아이콘으로.
- 위젯 클릭 판정은 x/y/w/h 상자 기준 — 상자 밖으로 그려진 글자(눈금 숫자 등)는 클릭해도 선택되지 않음.
- 대화상자·편집기 문구 i18n 미적용(한글 하드코딩).
