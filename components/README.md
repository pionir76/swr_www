# components — 독립 UI 부품

화면 여러 곳에서, 그리고 다른 프로젝트에서도 쓸 수 있는 UI 부품을 둔다.

규칙:

- **부품 하나 = 폴더 하나.** 코드·스타일·사용법(README)을 함께 둔다. 폴더째 복사하면 다른 프로젝트에서 동작해야 한다.
- 이 프로젝트의 다른 코드(`config.js`, `WHMI`, 페이지 스크립트)에 기대지 않는다. 외부 라이브러리도 쓰지 않는다.
- 전역 이름은 부품마다 하나(예: `window.ColorPicker`). 스타일 클래스는 부품 접두어를 붙인다(예: `.cpk-*`).
- 스타일은 부품이 스스로 불러온다(스크립트와 같은 폴더의 CSS). 쓰는 쪽은 스크립트 하나만 불러오면 된다.
- 항상 불러오는 공통 파일에 넣지 않는다. 쓰는 화면이 필요할 때 불러온다.
